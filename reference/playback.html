播放命令、快照与时间 ​

此参考用于插件调用或实现播放能力，不公开宿主算法。通过 query_interface 获取接口；snapshot 先设置 size，返回的是值。

快照标识 ​

字段单位/含义
track_id媒体曲目 ID，不能当数组行
position_us / duration_usint64 微秒
sampled_ns单调采样时间，纳秒
output_frame音频输出帧，不是显示帧
generation曲目/提供者时代标识，拒绝旧结果
revision时间重定位变化标识
seek_serial / landed_seekseek 请求与落地序列
feature_epoch音频特征连续性标识
sample_rate音频采样率
energy/bass/mid/high/accent同音频时间轴的特征值

flags 组合：ACTIVE=1、PAUSED=2、CLOCK_READY=4、SEEKING=8、FEATURES_READY=16。只在对应 READY 标志存在时消费有效时钟或特征；active 不等于正在播放，paused 可以同时存在。

不要用 now_ns 的经过时间自行累加音乐进度。动画可用绘制时钟，歌词/频谱与进度使用播放快照。seek 预览是局部 UI 状态，不是已经听到的音频位置。

客户端命令 ​

kind用途关键参数
TOGGLE播放/暂停切换无
NEXT / PREVIOUS当前规则下下一首/上一首无
SELECT选择目录曲目index = 目录行
QUEUE_SELECT选择真实队列项index = 队列行
MODE修改播放模式index = 模式 ID
PAUSE / RESUME明确暂停/恢复无
SEEK请求跳转position_us，seek_origin

其余 OPEN/STOP/PRIME/CLEAR_PRIME/REAP/REMEMBER 属于提供者/生命周期操作。普通 UI 插件不要随意重新 OPEN 以实现暂停或每次 seek，这会改变 generation、fd 和资源所有权。

command 返回 0 执行、1 接受但延后、负数拒绝。帧内提交后不保证同帧 position 已改变，不能重复发命令“催进度”。

调用片段 ​

c
LyraPlaybackSnapshotV2 state = {0};
state.size = sizeof(state);
if (playback->snapshot(playback->user, &state) == 0) {
    int playing = (state.flags & LYRA_PLAYBACK_ACTIVE) &&
                  !(state.flags & LYRA_PLAYBACK_PAUSED);
    /* 根据 playing 绘制，不创建另一套音乐进度 Timer。 */
    (void)playing;
}

LyraPlaybackCommandV2 command = {0};
command.size = sizeof(command);
command.kind = LYRA_PLAYBACK_QUEUE_SELECT;
command.index = desired_queue_row;
int accepted = playback->command(playback->user, &command);
if (accepted >= 0) host->request_frame(host->user);

队列 ​

queue 输出目录索引数组、容量和当前队列行。返回总数可能用于探测容量，先分配后读取，并检查当前 revision/曲目变化；不要把输出行直接写进 track_id。

音频提供者的事件与退出协议见提供者教程；歌词文本时间见数据接口。

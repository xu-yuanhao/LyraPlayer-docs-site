维护与部署文档站点 ​

站点是独立 VitePress 1.6.4 workspace。Markdown 在 docs/，公开插件契约在 reference-data/，SDK 在 sdk/，示例在 examples/。不含播放器实现源码，不进入 APK 构建。

sh
npm ci
npm run sync
npm run build
npm run dev
1
2
3
4

Node.js 20+；锁文件固定依赖。build 先检查参考覆盖、链接、SDK 与公开数据摘要、C 示例及闭源泄露边界，再生成本地搜索和静态站点。产物：docs/.vitepress/dist/。

公开契约更新 ​

维护者审查并更新 reference-data 中的默认配置、服务清单与 SDK release 资料，再运行 sync/build。脚本只读取文档仓库审核后的公开文件，不扫描、复制或依赖播放器源码。

SDK 使用语义变化时人工更新教程和集成验收；机器检查只能证明清单和链接一致，不证明所有行为正确。preview 契约不能仅靠一个标签被宣传成稳定发布承诺。

当前公网部署 ​

文档使用 GitHub Pages，HTTP MCP 使用独立 Vercel 服务。公开地址见Agent / MCP。源仓库保持私有；另一个公开发布仓库只存审核后的静态文档、SDK 和配置。

sh
npm run test:mcp
npm run prepare:vercel
1
2

GitHub Actions 使用仅限发布仓库的 deploy key 更新静态产物。Vercel 部署准备脚本只提取公开语料和 MCP 实现；不上传播放器源码或签名秘密。CLI 授权由 Vercel 官方管理。

其他静态部署 ​

任何静态托管可提供 dist。根路径用 DOCS_BASE=/，GitHub Pages 仓库路径用 DOCS_BASE=/LyraPlayer-docs-site/。

sh
DOCS_BASE=/LyraPlayer-docs-site/ npm run build
npm run preview
1
2

仓库提供 CI 检查和手动 Pages 发布流程。公开发布仓库 Pages 使用 main 根目录，.nojekyll 禁用 Jekyll 转换。工作流存在不表示已经上线；发布还需检查公开数据范围、品牌授权和 SDK 授权条款。

不含 analytics 或第三方搜索服务，本地搜索无需 Algolia。离线分发应打包完整 dist，不只保存 HTML。

权利与开放范围 ​

Lyra Player 为闭源软件。公开 SDK 头文件、示例和配置文档用于插件互操作；它们不授予播放器实现源码的使用或再分发权，也不意味着播放器采用开源许可证。具体 SDK/示例授权由项目方发布的条款决定，本站不替项目方虚构 MIT/LGPL 等声明。

VitePress 是 MIT 许可的第三方文档框架，不改变播放器许可。插件开发者需要给自己代码和依赖正确声明许可证，不能将宿主闭源与插件许可证混为一谈。

插件开发环境 ​

只需公开 SDK、Android NDK 和安装好的 Lyra Player。没有播放器源码前置条件，也不需要 Android 应用 keystore。插件 ZIP 不是 APK。

环境清单 ​

  • Linux 主机、Bash、Python 3.11+、ripgrep、Git（按需）。
  • Android SDK；教程使用 NDK 28.2.13676358。
  • arm64-v8a / API 26+ 的 Lyra Player 宿主和测试设备。
  • 本站 SDK 3 与示例包。

Windows/macOS 可使用对应 NDK toolchain，但随站提供的脚本目前验证的是 Linux 路径；不能直接把 linux-x86_64 路径复制到其他平台。

编译三个示例 ​

解压 SDK 包或使用文档 workspace：

sh
export ANDROID_HOME="$HOME/Android/Sdk"
bash examples/build.sh
1
2

产物：out/examples/example.root.zip、example.style.zip、example.rules.zip。脚本可用 LYRA_NDK_VERSION 选择 NDK。它不链接宿主 C++ 隐藏符号，不构建或签名播放器 APK。

在 Lyra 设置 → 安装插件选择 ZIP。先测试 style/rules，确认插件活动、参数及卸载恢复；根示例只演示 UI 接管。

用 NDK 的 aarch64-linux-android26-clang 编译 -std=c11 -fPIC -shared -fvisibility=hidden，include 指向 sdk/include，明确导出 lyra_plugin_init。C++ 同样跨库使用 C ABI 与 POD，入口需要 extern C。

记录 SDK ABI、宿主版本和测试设备。自定义新接口 ID 不会让现有闭源宿主自动支持它；必须查询已经发布的能力。

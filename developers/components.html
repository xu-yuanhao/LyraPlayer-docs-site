宿主组件与平台适配 ​

此页按界面区域列出宿主现有的公开配置和扩展入口。参数类型、默认值和约束以配置参考为准。

组件或区域配置表公开行为或扩展
外壳、抽屉和卡片布局shell、geometry导航扩展
底部播放条dock、theme播放接口
播放页、封面和流动背景player、cover_fx、flow样式与绘制
歌词player 的 lyric_* 参数歌词资源与播放进度由宿主管理
展开面板sheet、scrollScene 绘制协议
资料库和搜索search、profile、scroll媒体资源、私人资料库
设置页settings、theme声明式设置页协议
样式选择器style宿主提供 Bloom、Ember 和沉浸样式。插件可以向同一选择器提供样式描述

配置与应用样式 ​

  • 改全局配色用 theme。改尺寸和间距用对应区域的表。配置读写遵循配置接口和字段约束。
  • 播放页整体样式用样式与绘制接口。需要自绘时通过 Scene 提交画面。
  • 声明式设置行由宿主绘制。插件接收激活或确认消息，并处理校验、持久化和失败反馈。行标记、禁用状态、当前值和可用操作见设置页协议。

播放控件、进度条和队列 ​

播放按钮根据当前播放状态显示播放或暂停。上一首、下一首和进度拖动发出播放请求；宿主通过播放接口报告当前位置、时长及播放状态。替换这些控件时，用同一组公开状态更新按钮与进度条。播放接口、播放页配置。

队列面板按当前队列顺序显示曲目，当前行跟随队列提供的活动位置。模式菜单使用稳定模式 ID，队列行号用于定位当前队列中的条目。播放模式与队列、队列面板配置。

迷你歌词与展开歌词 ​

两处歌词共用曲目和播放时钟。带时间轴的歌词可以跟随播放，展开页可点击某句跳到该句起点。手动滚动会暂时暂停跟随，停稳后按 player.lyric_resume_ms 恢复。纯文本歌词可滚动阅读。译文、注音、和声与逐字高亮随歌词数据提供。

想调整的显示效果配置
迷你与展开页的正文字号player.lyric_main_mini_sp、player.lyric_main_expanded_sp
两处译文的字号player.lyric_translation_mini_sp、player.lyric_translation_expanded_sp
跟随切换的过渡时间player.lyric_follow_ms
歌词经过封面和控件时的过渡区域player.lyric_veil_dp，沉浸式样式可使用 immersive.lyric_veil_dp

实际支持的键和默认值以目标宿主的配置接口为准。歌词相关配置、配置接口。

局部替换歌词呈现可使用 lyrics 服务。从宿主查询 LYRA_INTERFACE_LYRICS，按曲目 ID 和 revision 更新缓存。读取句子和逐字时间前，将输出结构的 size 设为对应结构的大小。时间单位是微秒，播放位置取播放快照。读取 UTF-8 文本时可先传空缓冲区取得所需字节数，再分配并读取，所需大小含结束符。自行处理纯文本、缺失歌词和无逐字时间的句子。扩展入口、公开接口、播放时钟。

资料库、收藏与收听记录 ​

资料库呈现媒体列表、分组和收藏。播放、添加和删除等操作通过公开能力执行。收藏或收听记录为空时，扩展可以用对应数据的空状态呈现。权限和媒体访问由宿主或当前 Android Activity 处理。媒体操作、私人资料库、收听记录。

资料库分组标题与展开行 ​

艺术家和专辑页按曲目信息分组。「我的」提供歌单、流派、文件夹和语言入口。分组标题显示名称、封面和数量。可折叠分组展开后显示曲目行，收起只隐藏这些行。替换资料库呈现时，可以保留宿主的曲目元数据和媒体操作，并独立管理分组的展开状态。分类与文案配置、媒体数据插件、媒体操作。

曲目行封面尺寸使用 player.cover_dp。展开行缩进由宿主版本决定。SDK 配置快照列出 player.group_indent_dp。使用共享布局间距的宿主从 layout.min_gap_dp 取值，改变它也会影响其他使用共享间距的组件。调整缩进会减少展开行标题和副标题的可用宽度。写入前通过配置接口确认目标宿主包含该键。播放与列表配置、配置接口。

资料库滚动条、字母索引和横屏列 ​

支持 library 配置表的宿主可通过 library.rail_dp 设置滚动条宽度，library.rail_hit_dp 设置触摸范围，library.rail_min_dp 设置最小滑块长度。触摸范围至少应等于可见宽度。字母索引字号使用 library.index_sp，单位为 sp。字母索引用于按字母排序的曲目列表，拖动滚动条时会标出当前位置对应的字母。

支持 landscape.cell_dp 的宿主用它计算资料库横屏列数。可用宽度达到多个单元宽度时可以显示多列，窄窗口至少保留一列。竖屏使用单列。完全自绘的资料库从帧布局取得可用区域，在自己的绘制与触摸处理中使用同一列布局。像素、密度和字体缩放、导航扩展。

外部媒体集合入口与曲目列表 ​

实现集合目录能力的媒体提供者可以在资料库「我的」中提供集合入口。入口显示集合标题。打开入口后，宿主按集合 UID 请求内容，曲目列表显示该请求已发布的条目。离开集合时，宿主取消浏览请求。点击曲目后，播放队列保留自己的条目，退出集合仍可继续播放。集合目录、媒体数据插件。

搜索框和结果行 ​

search.min_text_width_dp 为搜索框文本和结果行文本设置统一的最小测量宽度，默认 40 dp，必须大于零。search.field_text_reserve_dp 为搜索框文本预留额外横向空间，默认 32 dp，可设为零。搜索面板的高度、搜索框外边距和结果行高度仍各自由对应的 search 字段控制。搜索配置。

搜索结果可能来自本地曲库、媒体源或插件仓库。媒体结果展示曲目信息和封面，仓库结果展示插件名称、版本、大小和当前可用操作。仓库返回的行号只在当前版本有效，更新目录后需要重新查询再使用行号。若插件只提供媒体数据，默认搜索页仍可展示结果和封面。媒体资源、服务目录。

Android 布局和能力 ​

宿主从 Android 8（API 26）起支持，正式插件应提供 arm64-v8a 构建。插件使用公开帧和布局数据适配当前窗口尺寸及安全区。横屏、竖屏和有系统栏遮挡的窗口都应使用实际可用空间做绘制和命中。尺寸单位查对应配置键的定义，绘制坐标查 Scene 协议。

调用 Android 能力时，遵循Android 平台契约的线程、引用和权限要求。能力可用性按运行设备版本及宿主声明判断。

像素、密度和字体缩放 ​

通过 LYRA_INTERFACE_PRESENTATION_CONTEXT（17）在帧线程读取 LyraPresentationSnapshotV3。调用 snapshot 前将 size 设为 sizeof(snapshot)，并检查返回值。整卡片样式的绘制回调优先使用本次回调收到的卡片矩形，选择器预览时这个矩形可能比主卡片小。

输入使用方式
width、height 与 card、cover、library 等矩形使用当前窗口的像素坐标。自绘和触摸命中共用同一矩形
配置键定义为 dp乘以当前 density 后用于像素布局
配置键定义为 sp乘以当前 density 和 font_scale 后用于文字布局
安全区宿主默认组件已处理自身布局。扩展叠加内容可以使用宿主提供的区域矩形。完全自绘的根若需要原始系统栏或挖孔内边距，可通过当前 Android Activity 查询系统能力

窗口旋转、大小变化或系统字体缩放改变后，按新的帧数据计算绘制与命中。缓存文字布局时，把实际文字宽度和换算后的字号纳入缓存条件。Android 进程、线程和权限的约束适用于完全自绘的根和局部扩展。公开 SDK、样式与绘制、Android 平台契约。

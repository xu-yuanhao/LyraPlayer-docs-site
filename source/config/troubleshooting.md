# 配置排错

| 现象 | 排查 |
| --- | --- |
| 行号语法错误 | 双引号、转义、行内注释、完整 TOML 不支持语法 |
| bad type | 将布尔写成字符串，或数字写成引号字符串 |
| invalid configuration | 范围或跨字段关系；查看 宿主返回的校验结果 |
| 未生效却没报错 | 未知键无消费路径、外部/内部根优先、插件替换默认实现 |
| 修改了其他语言文件没变化 | 当前默认只加载实际指定文案文件 |
| 颜色透明度不对 | 八位格式是 AARRGGBB |
| 多个表重复 | 合并到现有表，避免重复键依赖 |
| 改大字体后遮挡 | 布局和可用宽度也需验收，不只字重/字号 |

## 配置版本

插件 schema 只声明当前键与 schema\_version，不提供旧键别名或自动迁移。修改参数契约时同步更新插件、配置示例和说明；宿主仍保存用户文件，未知键会按配置校验规则处理。

新插件参数通过 schema 声明、读取并测试，不能用不存在的宿主默认键代替。不要只在 README 写“支持”而实际没有读取。文档生成器会覆盖默认键清单，但复杂语义变化仍需人工审查教程。

## 反馈材料

提供最小覆盖片段、版本、活动插件及错误，不发送完整含敏感 URL/token 的个人配置。参考公钥是公开材料，私钥和签名密码不是配置调参内容。

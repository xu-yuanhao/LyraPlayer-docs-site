# 实际支持的 TOML 子集

Lyra 的解析器不是完整 TOML 1.0 实现。当前支持表、键值、双引号字符串、数值和布尔，以及整行 `#` 注释。

```toml
# 整行注释可以
[player]
progress_relative_drag = true
lyric_main_mini_sp = 22

[theme]
light_surface = "#FAFAF8"
```

字符串支持 `\n`、`\t`、`\"`、`\\` 转义。数值由 strtod 解析，ui 数值读取另要求有限值。颜色允许 #RRGGBB 或 #AARRGGBB，八位不是 RGBA。

## 不要使用

数组、inline table、数组表、日期、三引号多行字符串、单引号 literal string、字符串内 `\uXXXX` 等转义，以及值末尾的行内注释。编写默认值和教程时使用实际解析器支持的格式。

需要列表时当前配置采用有语义的字符串，例如 `|` 分隔镜像、换行分隔规则。对这些字段必须按其各自约定写，不能统一改成 TOML array。

重复键目前后写覆盖前写，不建议依赖它。未知键被记录供插件扩展，不表示默认 UI 自动消费。把 `font.family` 等不存在的参数写进去不会产生功能。

## 文案

zh-Hans.toml 是文案文件名，不表示有运行时任意 locale 文件发现器。仅改 `app.locale` 不能保证自动加载另一语言文件；当前应编辑实际加载的文案覆盖文件，或实现声明完整的语言服务。

配置语法以本页列出的公开支持范围为准，不要求开发者阅读解析器实现。

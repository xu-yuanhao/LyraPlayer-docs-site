# 插件排错

| 现象 | 先检查 |
| --- | --- |
| 列表存在但未活动 | ABI、同 capability 竞争、dlopen/init/bind 错误 |
| 找不到入口 | 导出符号、C++ extern C、visibility |
| 导入被拒绝 | ZIP 结构、CRC、预算、路径、ELF 架构、id 与清单 |
| 安装提示同 ID | 本地不覆盖；使用版本明确的市场更新或先卸载 |
| query\_interface 返回 NULL | ID、版本、要求的 size、可选能力不存在 |
| 歌词/目录读返回 -1 | 索引或 revision 过期、文本 kind/field 无效 |
| 绘制后崩溃 | 图像借用寿命、worker 指针、卸载线程、数组 count |
| 提供者无法卸载 | STOP 未收束、quiesce 未完成、回调仍在旧库 |
| 新参数没生效 | schema 注册/范围、表声明、下一帧激活、文件路径 |
| 市场更新不出现 | version 可比较、已验证目录、镜像附件存在 |
| 外部歌词/视频读不到 | Android 存储授权、来源类型与可读路径 |

## 记录问题

给出宿主版本、插件 id/version/ABI、设备 API/架构、复现动作、是否其他同能力插件、相关错误日志。不要附 keystore、密码、私钥、用户音乐或歌词正文。

```sh
adb -s YOUR_DEVICE_SERIAL logcat -d -s Lyra
```

日志可用于控制/加载诊断，不证明听感。不要为让结果“通过”而移除断言、扩充架构基线或把缺失接口强转使用。

## 回退

通过外部插件列表卸载，默认服务恢复。根插件接管 UI 后可能没有默认设置入口；开发时保留测试安装和受控恢复路径。不要承诺在任意正式 Android 包都能用 run-as 操作私有目录。

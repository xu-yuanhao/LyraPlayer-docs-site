类型、范围与跨字段校验 ​

先检查 TOML 语法，再检查与 defaults/schema 的类型一致，最后由宿主检查范围与跨字段约束。默认键是字符串/数值/布尔三类，不强制把所有整数形式字段当作独立整数类型。

已确认的约定 ​

  • UI 数值要求有限，NaN/Infinity 不能作为有效数值进入配置。
  • 颜色是字符串，长度 7 或 9，格式 #RRGGBB / #AARRGGBB。
  • 播放模式 ID 必须为 0..2147483647 的整数；是否有提供者支持该模式由模式目录决定。
  • 个人分类歌词预算 >0 且 ≤4194304 字节；语言阈值还有本地规则界限。
  • 仓库 timeout 为 1000..60000 ms、maximum_rows ≤32、index_limit_bytes ≤1048576；其他字段也有共同界限。
  • 插件动态参数按声明 MINIMUM/MAXIMUM/INTEGER 检查。

字号、透明度、布局、过渡和粒子/波纹相关字段还包含各自约束；完整参数组合应通过宿主配置接口写入并验证。不要猜测跨字段组合能自动通过。

为什么不直接接受未知字段 ​

未知键可由声明 schema 的插件接管，也可以通过声明表读取。没有注册 schema 或消费路径就不自动成为新功能。未知字段列表用于诊断；不能把“文件未报错”理解为功能已生效。

原子激活 ​

写入会保留其他配置与注释，参数校验通过后请求帧边界激活。插件不要在 worker 绕过配置模块直接改当前模型，也不要在每帧把同一值反复写到磁盘。

状态栏对比与首帧时间 ​

theme.status_picker_inset、status_panel_fraction 和 status_cover_dim 是 0–1 的比例。status_initial_luma、status_light_luma、status_dark_luma 是 0–1 的亮度阈值，必须满足 light ≤ initial ≤ dark，形成明暗切换迟滞，避免图标在边界频繁闪烁。默认值保持原行为；这些配置控制系统图标对比，不改变播放页主题。

quality.initial_frame_ms 必须大于 0，表示尚无上一帧时间时的动画步长，默认 16 毫秒。后续帧使用实际帧间隔；该参数不会锁定屏幕刷新率。

样式与绘制教程 ​

使用 examples/style.c。插件在 query_interface 发布 LyraStylesInterfaceV3，count 返回描述数，describe 填写 LyraStyleDescriptionV3。

c
static const LyraStylesInterfaceV3 styles = {
    sizeof(styles), LYRA_INTERFACE_VERSION, 0, count, describe
};
1
2
3

一个不同 id 添加一种样式；相同 id 可替换内置描述。使用稳定、带命名空间的 id，例如 example.third，不要每次版本更新更名。

宿主预设与配置 ​

预设 IDbackground_variant默认呈现
bloom0默认播放页，使用 Bloom 背景
ember1默认播放页，使用 Ember 背景
immersive2沉浸式播放页，使用沉浸布局与背景效果

style.active 保存当前样式 ID。选择器的间距、缩放和动效由 style 表控制，主题色由 theme 表控制。插件在描述中省略 paint 时，宿主按所选变体绘制。扩展 API 对描述大小和变体编号进行校验。样式选择器配置、主题与换肤。

已选的插件样式被卸载时，同 ID 有内置描述便恢复该描述。没有内置描述的条目会从选择器移除。已保存的样式 ID 暂时不可用时，宿主显示 Bloom 并保留原配置。重新安装提供该 ID 的插件后，宿主可按原配置恢复选择。代码持有的绘制资源要覆盖回调的实际使用期，样式描述由宿主复制。

宿主预设覆盖清单 ​

播放页样式是唯一走 LyraStylesInterfaceV3 目录的可替换预设：bloom/ember/immersive 由宿主集中提供，插件用同一接口增删；style.active 保存选择，style 表管选择器，immersive 表管沉浸变体。

其他区域没有第二套样式目录，按证据分三类：

  • 主题：theme.follow_system/theme.dark 只选亮/暗，theme.tint_*、theme.transition_ms、theme.status_*_luma 是参数；主题控制器统一产出调色板供全站使用，不是命名预设列表。
  • 可视化强度：visualization.strength 取 low/medium/high/custom，上下限在 visualization.minimum/visualization.maximum，自定义值在 visualization.custom；参数键集中在可视化设置模型与 visualization_parameters 文案。
  • 播放背景与进度条：流动背景由 flow 表颜色/形变参数和当前播放样式的 background_variant 决定；进度条外观用 player.progress_style 选择。接受三个整数值：0 为带辉光和渐缩的默认样式，1 为纯色，2 为渐变。

设置、资料库、搜索、壳层、歌词、关于/支持等页面没有独立预设目录：它们消费共享主题调色板和各自已声明的配置表（settings/shell/system/geometry/search 等）。需要新增区域预设时，应先定义公共描述/目录接口再接入选择器，不要在页面里散落预设表。

列出与选择样式 ​

  1. 从宿主查询 LYRA_INTERFACE_STYLES。用 count 和 describe 枚举当前可用描述。把输出结构的 size 设为 sizeof(LyraStyleDescriptionV3)，成功后读取 id 和 label。索引可能随插件安装和卸载变化，持久化时使用 id。
  2. 已保存的选择可从配置接口读取 style.active。它表示用户选择的 ID，选择器的临时预览和缺失样式的回退可能显示其他卡片。
  3. 使用 LYRA_INTERFACE_CONFIG 的 write 选择样式。值是 TOML 字符串，例如 C 参数 "\"ember\""。写入成功后在帧边界生效。接口或目标样式缺失时，可保留宿主的选择器入口。配置接口。

默认背景或整卡片绘制 ​

background_variant 选择宿主播放卡片的形态。Bloom 和 Ember 共用默认卡片布局，沉浸变体使用自己的布局。选择器为每张预览卡分别使用它的变体和卡片矩形。预览卡的尺寸可能比当前播放卡片小，旋转窗口后也可能改变。

设置 paint 回调时，插件负责整张卡片的内容。回调的 x/y/w/h 是本次绘制的卡片矩形，通过 submit 在同一坐标内提交画面。需要歌词、控件或播放信息时，从相应的公开接口取值。只想使用宿主的卡片和控件时，可以省略 paint，选用上表的变体。

input 处理该样式的输入；返回 0 让未消费事件继续进入默认导航。选择器打开期间输入由选择器处理，不自行绕过选择器命中。

Scene 协议 ​

基础命令包括实色、封面、图标、短雾、流动背景、glyph、RGBA image。扩展文字层提供 tracking、词间距、方向、对齐、裁剪、模糊、扫光、变换中心与缩放；形状层提供渐变与边缘材质。具体字段以SDK为准。

颜色为浮点 RGBA，几何为当前传入的像素坐标；dp 通过 density 换算，sp 还需字体缩放策略。不要混用 normalized ripple 中心与像素位置。

图标图集只含上一首、播放、暂停、下一首，不含启动三叶 Logo。封面 key 与资料库标志不能随意混用；插件应查询目录和有效图像语义而不是猜编码。

文字和字体 ​

glyph/text layer 接受 UTF-8 text 和 font。当前 Android 后端支持系统字体族名，绝对路径字体由 Typeface.createFromFile 读取，失败回退 sans-serif。字体文件必须在应用可访问路径；自定义 .ttf/.otf 不因为放 ZIP 里就自动切换全站字体。

默认字号由 [player] 等表控制；当前没有承诺一个默认全局 font 配置键。完整字体选择 UI 或默认全局字体功能需要新增配置及消费路径，或由自定义 UI 插件实现。不要发明不存在的 font.family 键。

生命周期验收 ​

验证选择、缩放、切歌、暂停、横竖窗口变化、输入消费、卸载与缺失接口回退。不要在每个稳定帧分配新大数组；声明被宿主复制不意味着 paint 持有图像可以立即释放。

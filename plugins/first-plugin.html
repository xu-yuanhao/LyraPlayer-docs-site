第一个插件：替换根界面 ​

本教程使用随 SDK 发布的可编译 C 示例。目标是证明根被真实替换，而不是给已有界面盖一块背景。根替换会接管全部输入；首次实验请选择可信的测试设备，并了解恢复方法。

取得 SDK 与示例 ​

此文档 workspace 自带 sdk/include/plugin/lyra_plugin.h、contracts.h 和 examples/root.c。它们是独立公开 SDK 的一部分；版本依据见快照。不要依赖宿主私有对象。

sh
cd LyraPlayer-docs
export ANDROID_HOME="$HOME/Android/Sdk"
bash examples/build.sh
1
2
3

产物在 out/examples/，其中 example.root.zip 是可安装包，另有第三样式和播放规则示例。构建使用 NDK 28.2.13676358 的 aarch64-linux-android26-clang。可用 LYRA_NDK_VERSION 指定本机同兼容配置 NDK；改变工具链后需要自己验证 ABI。

入口做了什么 ​

c
__attribute__((visibility("default")))
int lyra_plugin_init(const LyraHostV2 *host, LyraPluginV2 *out) {
    if (!host || host->abi != LYRA_PLUGIN_ABI || host->size < sizeof(*host))
        return -1;
    *out = (LyraPluginV2){0};
    out->size = sizeof(*out);
    out->abi = LYRA_PLUGIN_ABI;
    out->id = "example.root";
    out->kind = "frame";
    out->version = "1.0";
    /* 完整示例继续填 on_frame、on_input。 */
    return 0;
}

入口检查宿主版本和大小，填写 ABI、身份与回调。C++ 插件用 extern "C" 导出此函数，仍以 C POD 数据跨库。-fvisibility=hidden 时明确导出入口。

on_frame 构造局部 Scene 并通过 host->submit 提交；文字和命令在 submit 时被复制。on_input 返回 1 消费输入。示例画面只演示替换，不是可用的完整播放器。

查看完整头文件；下载 root.c。

打包与安装 ​

text
example.root.zip
  manifest.toml
  plugin.so
1
2
3

清单声明 type = "frame"，id 与插件入口一致。ZIP 不需 APK 签名；它不是 APK，不要改后缀后安装到 Android 包管理器。在 Lyra 设置 → 安装插件选择 ZIP。

根示例没有设置页面的导航能力，可能让默认卸载入口不可见。调试时优先测试 style/rules；测试根之前备份配置，并采用可操作应用目录的开发设备或使用全新测试安装。非 debuggable 正式包的 run-as 不保证可用，不能承诺一条 adb 命令一定删除它。

验证 ​

sh
"$ANDROID_HOME/ndk/28.2.13676358/toolchains/llvm/prebuilt/linux-x86_64/bin/llvm-readelf" -h out/examples/example.root/plugin.so
"$ANDROID_HOME/ndk/28.2.13676358/toolchains/llvm/prebuilt/linux-x86_64/bin/llvm-nm" -D out/examples/example.root/plugin.so
1
2

确认 ELF AArch64、导出 lyra_plugin_init、ZIP 根目录正确。手机验证安装、活动状态、画面接管、输入和卸载恢复。编译通过不能替代这些测试。

加载、生命周期与安全卸载 ​

宿主读取有效 manifest，按 capability 选择实现，动态加载 plugin.so，调用导出入口，再执行可选 init/bind。帧边界更新服务，而不是工作线程直接改注册器。

回调用途
lyra_plugin_init(host,out)校验 ABI，返回插件描述
init(host)初始化插件资源；失败拒绝活动实现
bind(host)绑定上下文与模块接口
on_frame(host,time_ns)服务被根路由调用时执行
on_input(host,input)处理命中输入，1 表示消费
query_interface(...)发布可选接口，缺失返回 NULL
shutdown(host)终止线程、撤销回调、释放持有资源

不要假定私有注册器实现细节，不假定 on_frame 每个显示刷新都无条件执行。需要继续动画时调用 request_frame。

接口寿命 ​

接口表及其 user 在所属模块存续期间有效。不要缓存外部提供者接口跨卸载，也不要从工作线程调用查找/注册。公开值快照可以复制留存；任何指针都必须按对应 lifetime 管理。

动态库卸载前必须不存在执行库代码的线程或回调。播放 provider 的 quiesce 失败时保留旧提供者和库，不能为了 UI 显示“卸载成功”强行 dlclose。插件的其他线程也必须由 shutdown 结束。

配置与目录卸载 ​

样式/schema/modes 描述由宿主复制或依所有者保存；移除所有者恢复内置描述。用户保存的配置和模式 ID 不随卸载删除。模式提供者缺失时实际使用安全回退，重新安装后可恢复保存的 ID。

多包竞争 ​

当前注册器优先外部根，再内部根；同 capability 内还有确定性 ID 排序。该行为只是当前实现，不应成为跨插件编排协议。外部列表保留发现的有效但未启用包；“存在”不等于“活动”。避免同一设备安装多个都想接管 playback 的包而期待它们串联。

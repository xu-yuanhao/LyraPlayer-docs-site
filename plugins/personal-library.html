个人歌单 ​

LYRA_INTERFACE_PERSONAL_LIBRARY（21，plugin/personal_contracts.h）管理个人歌单：创建、解散、增删曲目、文件删除确认、队列编辑。帧线程标签操作。

操作 ​

LIST(1) 返回 revision HANDLE + UTF-8 JSON 快照（playlist/track ID 为 I64，字符串含结尾 NUL）；CREATE(2) 拒绝空名/重名；DISSOLVE(3) 不删音频文件；ADD(4) 加曲目；DELETE_FILE(5) 走 Android 用户确认流；POLL_DELETE(6) 每确认移除返回一次 track ID（0 无挂起，负值取消/失败）；SET_INPUT(7)；PLAY_NEXT(8) 与 BLOCK_FOLDER(9) 保持播放不中断，后者把曲目目录持久化到既有扫描策略；EDIT_QUEUE(10) 用 ID/TRACK 调整队列位置，TRACK=0 移除，不删文件。

存储错误不提交。歌单引用可用 PROVIDER/UID 保存来源媒体身份，不能与 TRACK 混用。

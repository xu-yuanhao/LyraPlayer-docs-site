Android 桥与权限 ​

通过 host->java_vm 与 host->android_context 使用 JNI，context 是当前 Activity。插件自行管理线程附着与本地引用，不跨帧保留无效 Activity 引用；非 Android 宿主可为空。

Java 桥不是冻结的跨平台 C ABI。反射签名必须核对 SDK 对应宿主的公开桥资料，不能从旧教程抄已变更重载。用户权限依 Android 清单和系统授权状态决定。

常用桥 ​

方法语义
setStatusBarHidden(boolean)Android 窗口状态栏
choosePlugin(String)、takePluginFd()系统选择器、转移选中 ZIP fd
listPlugins(boolean)原生插件清单快照
isSystemDarkTheme()、applyLyraTheme(boolean)主题目标桥
readSiblingText(long,String,int)可访问同名侧车歌词，有界读取
syncMotionArtwork(...)当前动态封面叠层，有重载
clearMotionArtwork()清理封面叠层
requestVerifiedResource(...)、poll/cancel通用签名/摘要校验下载

takePluginFd 返回 -1 未选、-2 失败，非负 fd 转移给调用方，需关闭。extractMotionArtwork 的输入和输出 fd 是借用，不是同样的转移语义。

外部封面与侧车 ​

“知道路径”不等于“有读取授权”。Android 版本、MediaStore 所属类型、应用私有目录和用户授权影响可访问性。插件无法运行时添加宿主清单未声明的权限。使用宿主提供的 Activity 或公开数据接口，不给每一种能力追加专有 Host 函数。

插件作者只能使用已发布桥，不能给闭源宿主自行新增 Java 方法。发布前在最低支持版本与当前系统验证反射可达性。

syncMotionArtwork 顺序：trackId、title、enabled、preferEmbedded、embedded、sidecars，扩展重载再加 directories、budget，最后 x/y/w/h/radius、playing。几何为像素。budget 为读入字节预算。extractMotionArtwork/normalizeMotionArtwork 返回 0 静态或不支持、1 动图、2 视频。

资源桥 start 返回请求 ID；poll 等待为空，完成为 1\n<JSON>（验证索引）、2\n<owned fd>（验证包）或 -1\n<diagnostic>。owned fd 转移给调用方，消费或关闭；取消请求不保证你已取出的 fd 自动关闭。接口也受宿主版本限制，找不到方法时清理 JNI exception 并回退。

JNIEnv 不能跨线程缓存，worker 附着当前线程后获取自己的 JNIEnv；只在自己附着时负责 detach。删除 local refs，不把局部 jobject 当长期持有。每次获取类/方法或调用后检查异常，错误不继续调用空 method ID。

# Lyra Player 插件 SDK

ABI 3 · 公共接口版本 3 · Android 平台 IDL 9。

`include/plugin/` 为 C 头文件。`android-platform-v9.json` 记录 JNI 方法声明及常量。`examples/build.sh` 用 Android NDK 构建并打包三个示例。设置 `ANDROID_NDK_HOME` 后执行该脚本，再在 Lyra Player 的设置页安装 `out/` 下生成的 ZIP。

[开发文档](https://xu-yuanhao.github.io/LyraPlayer-docs-site/) · [接口目录](https://xu-yuanhao.github.io/LyraPlayer-docs-site/reference/abi.html)
